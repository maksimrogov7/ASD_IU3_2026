## Запуск в VS Code

1. Откройте папку репозитория.
2. Откройте нужный файл `src/main/java/ru/bmstu/lab1/task_N/Main.java` в этом модуле.
3. Нажмите **Run** над методом `main`. Данные вводите в терминале.
4. Сначала введите `n`, затем `n` целых чисел.
   Для задач 2, 3, 4 дополнительно введите `x`, для 10 — `k`, для 12 — `s`.

Числа можно разделять пробелами или переводами строк. Индексация начинается с нуля.
Программы не печатают приглашения к вводу, чтобы выход соответствовал условию.
Для задачи 1 порядок ответа — минимум, затем максимум.
Для задачи 8 первая строка содержит положительные числа, вторая — отрицательные.
Пустой результат в задачах 4 и 8 печатается пустой строкой.

Пример для задачи 12:

```text
5
1 2 3 4 5
6
```

Ответ:

```text
0 4
```

## Сборка и проверка

Нужен JDK 21 или новее. При необходимости задайте `JAVA_HOME` на установленный JDK.
Maven Wrapper скачает Maven при первом запуске; отдельная установка Maven не требуется.

Из корня репозитория в PowerShell:

```powershell
.\mvnw.cmd -pl 31-Rogov clean verify
```

На Linux/macOS:

```sh
sh mvnw -pl 31-Rogov clean verify
```

Проверка запускает Checkstyle, JUnit и JaCoCo; сборка завершится ошибкой при покрытии строк менее 80%.
Отчёт покрытия: `31-Rogov/target/site/jacoco/index.html`.

После сборки можно запускать любую задачу из корня:

```powershell
java -cp 31-Rogov/target/classes ru.bmstu.lab1.task_1.Main
```

Модуль явно использует Java 21, что соответствует `style-guide.md` (Java 21+).
В родительском POM и исходном примере указана Java 25, поэтому сборка всего репозитория без `-pl`
на JDK 21 не поддерживается. Исходный пример не изменён.

- `task_1` … `task_12`: по одному самостоятельному классу `Main` с методом `solve`.

- `AlgorithmsTest`: 5 тестов, включая случайные проверки и большой массив.
